# Tic-Tac-Toe Prolog

A simple two-player, turn-based Tic-Tac-Toe game that runs in the terminal using SWI-Prolog.

## Features

- Two players take turns as `x` and `o`.
- The board uses positions 1 through 9.
- Invalid or occupied positions are rejected.
- The game detects wins and draws.

## Requirements

- [SWI-Prolog](https://www.swi-prolog.org/)

## How to run

1. Save or clone this repository.
2. Open a terminal in the project folder.
3. Start SWI-Prolog with:

   ```bash
   swipl tic_tac_toe.pl
   ```

4. At the Prolog prompt, run:

   ```prolog
   ?- start.
   ```

5. Enter a number from 1 to 9 when prompted.

## Board positions

```text
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
```
